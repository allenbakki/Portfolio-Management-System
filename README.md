# Folio

Folio is a lightweight app to build and preview a professional portfolio.

## What you can do
- Create your profile: name, title, contact, location, and bio.
- Add sections: Work Experience, Education, and Projects.
- Preview everything in a clean portfolio template.

## How it works
1. **Open Folio**.
2. **Sign Up**.
3. Go to the **Portfolio** page and fill out the form:
   - General info & Bio
   - Work Experience (add multiple entries)
   - Education (add multiple entries)
   - Projects (add multiple entries)
4. Open the **Deisgn Lab** to see your portfolio rendered.
5. Update the form anytime; revisit the preview to check changes.

## Run locally frontend
```bash
npm install
cd folio
npm run dev
```

## Run locally backend
```bash
npm install
cd backend/functions
node index.js
```

That's it! build your profile, preview it, and iterate.
